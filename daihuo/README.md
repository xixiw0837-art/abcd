# 带货起号方案：不露脸 · 居家厨房好物

> 你没说做什么品类，我选了**最适合新手、不用露脸、成本最低**的方向：居家/厨房/收纳小好物。
> 抖音负责短视频 + 橱窗出单，小红书负责种草笔记 + 引流，同一套素材两边一起用。

## 为什么选这个方向

| 条件 | 居家好物 | 说明 |
|---|---|---|
| 要不要露脸 | 不用 | 只拍手和产品，用手机就能拍 |
| 客单价 | 9.9~59元 | 买的人不太犹豫，新号容易出第一单 |
| 展示效果 | 强 | "使用前/使用后"对比很直观，容易火 |
| 素材来源 | 自己家 | 厨房、冰箱、卫生间、衣柜都能拍 |
| 复购和连带 | 有 | 一个人买了收纳盒，往往会再买别的 |
| 竞争 | 大但不饱和 | 赢在**场景真实**，不用比谁更专业 |

## 必须你自己做的事（我没法替你登录账号）

1. **注册/整理账号**：照着 `01-账号设置.md` 改昵称、简介、头像（10分钟）
2. **买3~5个样品**：选品清单里挑，单价低的先上，总预算控制在100~200元
3. **每天拍1条**：照着脚本拍，一条大概20~30分钟
4. **剪辑**：推荐用剪映（免费），脚本里每个镜头的时长和字幕都写好了
5. **发布**：抖音、小红书各发一次。时间建议：中午12点左右或晚上7~9点
6. **每周把数据给我**：填 `07-数据复盘模板.md` 发给我，我告诉你下周怎么改

## 预期（说实话）

- **第1~2周**：播放量几百到几千很正常，不要慌，这是平台在给账号打标签
- **第3~4周**：如果内容统一在一个方向，开始有稳定流量，出零星订单
- **1~3个月**：有一条爆了之后会明显好转。也可能不爆，那就按数据调整方向

收入不保证。坚持发**垂直内容**加**按数据调整**，是普通人成功率最高的方法。
