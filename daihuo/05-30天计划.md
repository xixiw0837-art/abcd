# 05 30天执行计划

## 每天固定动作（约1小时）

| 时间 | 做什么 |
|---|---|
| 10分钟 | 刷同领域爆款，收藏3条，记下它们的开头 |
| 30分钟 | 照着脚本拍1条、剪1条 |
| 5分钟 | 抖音、小红书各发一次（中午12点左右或晚上7~9点） |
| 10分钟 | 回复所有评论，在热门同行的评论区留有价值的评论 |
| 5分钟 | 记录前一天作品的数据 |

## 第3周：放大

- 找出前两周 **播放量前2名** 的视频，同类型再拍3~5条
- 播放量高但不出单 → 换商品，或者在视频里讲得更清楚"为什么值得买"
- 不出单也没流量的品类 → 停掉
- 第21天复盘

## 第4周：稳定

- 固定每周发片节奏：比如3条对比改造、2条实测、1条合集、1条干货
- 尝试 **"一镜到底改造"** 长视频（1~3分钟），适合小红书，涨粉效果好
- 考虑开直播：每天30分钟，展示自己家的东西（直播话术可以找我写）
- 第30天做月度复盘，我们一起决定要不要换方向

## 什么时候需要调整（判断标准）

| 情况 | 原因 | 怎么办 |
|---|---|---|
| 播放量一直 < 500 | 前3秒不吸引人，或账号标签乱 | 换开头，只发垂直内容 |
| 完播率 < 20% | 太长或节奏太慢 | 剪到15秒以内，删掉废话 |
| 播放量高、点车少 | 产品没讲清楚 / 价格吸引力不够 | 加一句"多少钱 + 为什么值" |
| 点车多、成交少 | 商品详情页或评价不好 | 换同类评价更好的店铺 |
| 突然掉流量 | 可能触发违规 | 查 06-避坑与违禁词.md |
