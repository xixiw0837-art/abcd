# 02 选品清单

## 选品标准（在精选联盟 / 小红书选品中心按这个筛）

| 指标 | 要求 |
|---|---|
| 价格 | 9.9~59元 |
| 佣金率 | ≥ 20%（越高越好，但别只看佣金） |
| 店铺评分 | ≥ 4.7，差评率低 |
| 近30天销量 | 有一定销量，说明有人买，但不要选几十万单的"神品"，太卷 |
| 展示效果 | **拍出来能看出变化** — 这是第一位 |
| 能不能寄样 | 优先选支持免费寄样的商品 |

> 每个商品**自己先用3天**再推。说不出真实使用感受的东西，拍出来没有说服力。

## 起步建议

- **先买第1、2、5号**：对比效果最强，最容易出第一条有流量的视频
- 总预算100~200元，后面优先申请免费寄样
- 橱窗里放 **8~15个** 商品就够了，多了显得杂乱，像营销号
- 每个商品记下：链接、价格、佣金、你自己的使用感受（写进 `07-数据复盘模板.md`）
