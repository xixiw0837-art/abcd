# 01 账号设置

## 昵称（选一个，两个平台用同一个）

- 小满的好物厨房
- 一只收纳控
- 租房也要好好住
- 家务偷懒研究所
- 30㎡的小日子

> 原则：一看就知道你做什么。不要用生僻字，不要用 "xx优选""xx旗舰"，这类名字像营销号。

## 简介

**抖音：**
```
不露脸的家务懒人
只分享自己家真在用的小东西
省时间 / 省空间 / 省钱
👇 橱窗里都是我用过的
```

**小红书：**
```
🏠 租房小家改造中
🧺 收纳｜厨房｜清洁 好物实测
✍️ 不接硬广，只写真实体验
📮 每天更新
```

## 头像和背景

- 头像：拍自己家整理好的一角，比如冰箱、调料架、衣柜，**暖色光、干净**
- 不要用网图，也不要用自拍
- 抖音背景图：一张整理前后的对比图，配字"跟我一起把家变好用"

## 开通橱窗（规则会变，以平台App内的提示为准）

**抖音：**
1. 完成实名认证
2. 我 → 右上角三条杠 → 抖音创作者中心 → 全部 → 电商带货 / 商品橱窗
3. 按页面提示满足要求，比如粉丝数、发布作品数，有的还要交保证金
4. 开通后进"精选联盟"选商品加入橱窗，发视频时挂小黄车

**小红书：**
1. 完成实名认证
2. 我 → 左上角三条杠 → 创作中心 → 更多服务，找"买手合作"或"带货"入口
3. 按要求开通。开通前可以先发笔记积累粉丝，笔记里只做种草，不要导流去其他平台

> 刚开始没开通橱窗也没关系。**先发内容涨粉**，达到条件再开，前面发的视频照样有用。

## 养号（第1周做，每天15分钟）

- 刷同类账号：搜"收纳""厨房好物""租房改造"，点赞、看完、评论
- 关注10~20个同领域博主
- 不要频繁改资料，不要一天发好几条，也不要刚注册就挂链接
